# OpsBrief

Локальный помощник руководителя инженерной команды. [English](README.md).

**Первый этап готов: автономный отчёт с расчётами.** Интеграции Jira, Ollama/Qwen,
история снимков, расписание и Алиса пока находятся в плане развития.
Демо работает без сети, модели и дополнительных Python-библиотек.

## Запуск на Mac

Нужен Python 3.11 или новее. Проверь: `python3 --version`.

```bash
git clone https://github.com/shilvlad/opsbrief.git
cd opsbrief
python3 -m opsbrief --input examples/demo.json --as-of 2026-10-19
open reports/weekly.html
```

Фиксированная дата нужна для воспроизводимого демо. Все сотрудники и задачи
вымышлены. Для текущих данных убери `--as-of`: будет использована локальная дата.
Отчёты HTML и JSON сохраняются в `reports/`, исключённой из Git.

## Что показывает отчёт

- Доступные часы после вычета отсутствий, встреч, сопровождения и резерва.
- Объём явно выбранных на неделю незавершённых задач и превышение доступных часов.
- Задачи без оценок или исполнителя, просрочки и зависимости.
- Дату исходных данных и их возраст.

В демо у DevOps 20 доступных часов и 24 часа задач — перегрузка на 4 часа.
У DBA 16 доступных часов, 8 часов оценённых задач и одна задача без оценки:
это **не означает**, что у DBA свободны оставшиеся 8 часов.
Закрытые задачи и бэклог не входят в недельную загрузку.

Это расчёт фактов, а не готовая AI-рекомендация. Назначения и сроки не меняются.
Программа принимает подготовленный JSON, а не произвольную выгрузку Jira.
Формат описан в [docs/input.md](docs/input.md). Рабочие данные храни в `data/` или `local/`.

## Разработка

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q opsbrief
```

Дальше: Jira API → история SQLite → локальная Qwen → расписание → приватный навык Алисы.
Расчёты выполняет код; модель будет формировать предложения со ссылками на задачи.
Алиса потребует отдельной разрешённой голосовой сводки: её текст передаётся Яндексу.

Лицензия Apache-2.0. В публичный репозиторий не добавляем корпоративные данные,
токены, реальные внутренние адреса или сформированные рабочие отчёты.
